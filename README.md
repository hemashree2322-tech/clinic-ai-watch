# Queue Predictor

Create a simple and clean frontend website for an “AI Hospital Queue Prediction System” using HTML, CSS, and JavaScript.

The website should have the following pages/sections:

HOME PAGE

Hospital name and logo

Title: “AI Hospital Queue Prediction System”

Short description: “Predict waiting time and manage hospital queues efficiently using AI.”

Buttons: “Book Appointment” and “Check Queue”

PATIENT REGISTRATION

Patient Name

Age

Phone Number

Department

Doctor Selection

Appointment Date

Appointment Time

Submit button

QUEUE STATUS
Display:

Patient Token Number

Patients Ahead

Current Token Number

Estimated Waiting Time

Queue Status: Waiting / In Consultation / Completed

AI PREDICTION DASHBOARD
Show simple cards:

Total Patients: 25

Patients in Queue: 12

Average Waiting Time: 35 mins

Available Doctors: 4

Add a simple line/bar chart showing predicted waiting time.

DOCTOR SECTION

Doctor Name

Department

Availability status

Current patient token

Estimated consultation time

Design requirements:

Simple blue and white healthcare theme

Responsive layout

Navigation bar: Home | Register | Queue Status | Dashboard

Rounded cards and buttons

Clean fonts

Beginner-friendly HTML, CSS and JavaScript

No complex backend

Use sample/static data for demonstration

Suitable for a B.E. Computer Science and Engineering college project

Make the UI simple enough to run directly in VS Code or an online HTML compiler.
